# VVF Smart Manager — User Guide & Manual

## 🌟 Welcome to VVF Smart Manager
VVF Smart Manager is your powerful, secure, and intelligent file manager designed for Android with privacy, security, and performance at its core.

---

## 📱 Core Features & How To Use

### 1. 📂 File Explorer
- **Storage Overview**: View real-time internal storage utilization with visual breakdown rings.
- **Categorized Tabs**: Quickly browse All Files, Images, Videos, Audio, Documents, and Downloads.
- **File Actions**: Long-press any file to copy, move, rename, share, delete, or move it to the **Secure Vault**.
- **Recycle Bin**: Deleted files are safely stored in the Recycle Bin for 30 days before permanent purging.

### 2. 🔐 Secure Vault
- **Master PIN & Biometric Access**: Set a 4-to-6 digit secure PIN or use your fingerprint/face unlock.
- **AES-256 Military Grade Encryption**: Files placed in the Vault are completely encrypted and hidden from other gallery and file explorer apps.
- **Restore / Export**: Restore files back to their original directory whenever needed.

### 3. 🧹 Cleaner & Duplicate Finder
- **Level 1 Duplicate Cleaner**: Instant file size & extension match.
- **Level 2 Deep SHA-256 Hash Matching**: Bit-by-bit cryptographic verification to eliminate identical duplicate files and free up storage.
- **Junk Cleaner**: Clears application cache, empty folders, and orphaned `.tmp` files with one tap.

### 4. 🔍 Search Engine & AI Intelligence
- **Core FTS4 Search**: Search across millions of files by name, extension, date, and custom tags.
- **AI Semantic Search**: Search files by conceptual intent using on-device lightweight AI embeddings.
- **Similarity Slider (70% - 95%)**: Fine-tune semantic tolerance to find related documents and photos.

### 5. ☁️ Cloud & Plugins
- **Google Drive Core**: Securely sync and backup your folders directly to Google Drive.
- **Plugin Store**: Download on-demand AI packages (ML Kit OCR, TFLite Semantic Search) without bloating the base application.
