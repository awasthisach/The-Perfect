# Room schema export

- `VVFDatabase` has `exportSchema = true`
- KSP: `room.schemaLocation = $projectDir/schemas`

## Important

Schema JSON **must be generated by Room/KSP**. Hand-written JSON breaks the build:

```
SchemaBundle.deserialize → kotlinx.serialization Json.decodeFromString FAILED
```

## Generate and commit (local or CI artifact)

```bash
./gradlew :core:database:kspDebugKotlin
# then commit:
# core/database/schemas/com.vvf.smartmanager.core.database.VVFDatabase/<version>.json
```

After the first successful KSP run, commit the generated `*.json` files so migrations stay reviewable in git.

Do not invent `identityHash` or field layout by hand.
